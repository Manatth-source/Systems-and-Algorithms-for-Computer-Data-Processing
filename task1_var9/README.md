Медленный способ: один проход поиска пары - O(n^2), после каждого слияния список уменьшается на 1, слияний до n−1 следовательно O(n^3) в худшем случае. Худший случай - когда все отрезки пересекаются. Память O(1)

Быстрый: сортировка O(n log n). Память: сортировка std::sort - O(log n) стека, результат - O(n) дополнительно.
